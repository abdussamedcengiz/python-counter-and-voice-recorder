# Python Alistirmalari

Python ogrenirken acilmis, iki klasorluk kucuk bir depo.

| Klasor | Icerik |
|---|---|
| `pythonTime/` | `time` modulu denemesi: epoch'tan bu yana gecen saniyeyi yazdiriyor |
| `seskaydedici/` | **Bos** -- yalnizca PyCharm proje dosyalari (`.idea`) var, Python kodu hic eklenmemis |

## Calistirma

```bash
python pythonTime/main.py
```

## Not

Depo adi bir ses kaydedici oldugunu ima ediyor ama o kod hicbir zaman
eklenmemis. Adi oldugu gibi birakildi, icerigin gercekte ne oldugu burada
yaziyor.
